# 3d-asset-archive

Archive for 3D project files, models, renders, and documentation.

## 可复用制作工具

[产品 CG 工作室 · 使用指南](skills/product-cg-studio/README.md) · [下载可转发的技能 ZIP](downloads/product-cg-studio.zip)

在支持 MCP 的客户端中，可直接检查 Blender 工程的装配和动作、比较两版模型的每毫米截面与倒角，并后台渲染或单独重出一个镜头。[安装本地 MCP 与试跑 DJI 折脚案例](skills/product-cg-studio/mcp/)

技能配图取自 DJI 口袋云台相机 CG 项目，涵盖起模、侧视结构迭代、六姿态、白模和成品特写。[查看 DJI 配图与来源](skills/product-cg-studio/examples/dji/sources.md)

只有概念或草图也可以起单。技能会先读图，向客户提至少 10 个与本项目有关的问题，查找真实相似设计，并把客户选中的特征落实到白模、装配、材质和镜头。[客户访谈](skills/product-cg-studio/references/concept-intake.md) · [DJI 产品参考板](skills/product-cg-studio/examples/concept/dji-references.md) · [从相机轮廓到白模的决策示例](skills/product-cg-studio/examples/concept/handoff.md)

从参考建模或已有工程起步，逐件核对连接、倒角、每毫米截面和实际绑定动作，修回源模型后完成 CMF 精修、多姿态效果图和动画。包内有批量工单、可运行的 Blender 检查与渲染脚本，以及带故障对照、工程和成片的原创示例。[截面对比](skills/product-cg-studio/references/sections.md) · [装配与动作复验](skills/product-cg-studio/references/assembly-and-rig.md) · [历史项目返工经验](skills/product-cg-studio/references/iteration-lessons.md)

多款产品并行时，每款工单可以单独记录尺寸冲突、裁决人、改模后需要重出的镜头和客户实际签收的版本。桌面支撑试用把这些设计问题落到了同一台 DJI 相机上，可下载白模查看底部供电与桌面支撑的关系。[工单与交付状态](skills/product-cg-studio/references/production-queue.md) · [桌面支撑试用与可编辑白模](projects/pocket-camera/desk-support-trial/)
