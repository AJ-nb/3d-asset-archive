# 装配、绑定与动作复验

在零件分界确定时就建立装配基准和基础绑定。先用可编辑模型做一次真实动作，找到最容易露馅的位置，再细化外表。以下记录随模型版本更新，可供下一位制作者复测。

## 逐件追踪支撑和装配

建立零件清单，给每个可见零件、内部接口和柔性连接指定稳定 ID。沿装配树把每个零件追踪至支撑件或基座，再补记树外的接触、导向和联动。一个子件有两个支承面或三处卡扣时分别建行。图案、覆膜、胶层、焊点等也应说明依附表面或接合区域。仅凭照片看不到的内部结构标为推定，注明可以解除不确定性的图纸、拆解或实测。

| 每个接口填写 | 需要回答的问题 |
| --- | --- |
| 子件、配合件、基准、证据 | 装配姿态和版本是什么？哪张图、哪个尺寸或哪块实物支持这个位置？ |
| 固定方式、支承面和对偶结构 | 力或位移经哪两个实体传递？螺钉有对应沉孔、螺纹座或螺母吗？轴有孔、轴肩及轴向保持吗？装饰条有母槽或胶面吗？ |
| 装配顺序、插入方向、紧固与拆卸路径 | 先装哪件？壳体闭合前能否放入？工具和紧固件有进入空间吗？拆卸时先解锁什么？ |
| 类型、轴系、公差或间隙、止挡 | 定义的坐标系是什么？孔轴是否同心？壳厚、倒角和止口会否吃掉支承面？明确几何意图、单位、上下界和依据。 |
| 状态、证据、修复与复测 | 记录静止剖面、最差姿态和相邻件。失败时保存旧版视图、改动部位、新测值和剩余未知。 |

在主体隐藏与显示两种状态下看真实配合。对孔与轴至少复核沿轴向分开的两个站位、孔径和轴径、插入深度、端面与止挡。对卡扣检查接合及解除路径，对插头检查插入轴、壳体和插座背部空间。先改造成错误的几何或枢轴，再重检邻近接口和受影响镜头。例如面板开孔偏移时，移动贴花不能修复内部插座。

检查完整闭合实体的占用。两个物体存在包容关系时，三角面可能完全没有相交边。对关键硬件用可靠的闭合实体布尔交量或 CAD 截面与最小距离交叉核验。壳体应建真实腔体，记录网格精度、布尔容差、压配和接触的设计意图。软垫压缩及过盈配合需有依据。制造、承载或人身安全相关用途另需合适人员核算配合公差、材料、工艺、载荷和性能。

## 分清机构和形变

| 类型 | 建模、驱动与关键动作 |
| --- | --- |
| 刚性固定件／铰链 | 固定件随真实基座运动。铰链以实际轴心、轴向单自由度旋转。锁定多余自由度，校验零位、正负转向、止挡及中段间隙。用刚性变换、骨骼父子或单骨满权重维持形状。 |
| 滑动／伸缩 | 按实际导轨建立局部位移方向和行程。拉出后仍需有支撑、导向重叠量和行程止挡。记录偏摆或侧向偏移。 |
| 球关节／多轴联动 | 分别定义摆动、扭转及解剖或机械限位。复合姿态受球座、邻件等共同限制。齿轮、皮带、连杆另记轴距、传动方向、比值和相位。 |
| 线缆／软管 | 明确两端接头、中间夹点和随动件。逐姿态量中心线路径长度、余量和最小弯曲半径，验证应力释放、扭转、活动回路及防夹空间。长度、半径和可压缩量以实物或材料资料为据。 |
| 角色／软质外皮 | 在中立姿态建立拓扑、骨骼局部轴和父子层级。围绕弯曲面布环线，给受压、扭转区留足形变网格。逐段检验边长变化、关节截面、轮廓和体积。按需用扭转骨、辅助骨或姿态修形，再检查纹理和褶皱。 |

保存未施加绑定的可编辑基准与可回放测试动作。确认单位、比例、朝向、骨骼局部轴、对象变换、父逆矩阵及命名。对硬件和软包混合件分区驱动。柔性网格核对所有顶点归一权重、有效变形骨、影响数和允许影响区；归一正确的顶点仍可能被错误骨骼牵动。用棋盘格和中性光观察默认、常用、扭转和压缩姿态，对弯曲区同时看内侧夹挤、外侧拉长和远端误动。

控制器只为实际动作配置。IK 设极向、长度与伸展条件，FK 检查局部旋转和继承。提供 IK/FK 切换时，先把目标和极向对齐到当前链姿，再切换；对比切换前后末端及各节世界变换，回放前后一段看跳变、翻转和速度突变。活动摄影机移开后再从固定视角检查接触、重心和落地支撑。

## 全行程和组合复验

1. 为每个活动件列允许状态与禁止状态，注明联锁、解锁、收纳与工作姿态。爆炸演示另外记录拆出顺序和展示位移。
2. 生成静止、单轴往返、常用动作和可达的复合动作。测试两轴同时走、交错走，以及一个停在极限而另一个动作的情况。角点之间也要测试。关节受联锁时用真实联动关系限定可达空间。
3. 在工作区内按角度或位移取样，再按长臂端速度、最小间隙、薄壁厚度、插值过冲加密，保存最差位置和帧间片段。逐对检查实体占用、动态间隙、连接连续性、轴向保持、线缆与邻件，以及关键柔性截面的伸缩。需要证明整个运动区间安全时，采用适用于该模型的连续碰撞、保守扫掠包络或解析界限，另记覆盖范围与误差。离散采样只能支持已检姿态的结论。
4. 保存失败姿态作为回归。修复后重跑原动作、边界和相邻接口；修改源几何、来源尺寸或绑定后刷新依赖的截图、动作和镜头。按最终渲染层级、约束与细分复核，记录用于测试的场景版本。

## 运行 Blender 样件

从本技能目录运行，命令中的 `blender` 应指向可在后台启动的 Blender。样件由脚本从空场景建立，包括销、固定耳、刚性摆动耳、骨骼和带渐变蒙皮的管段。写入新的输出目录，每个样件和报告各占一个文件。

```sh
blender -b --factory-startup --disable-autoexec --python-exit-code 1 -P examples/rig-check/make_fixture.py -- --out rig-demo/good.blend
blender -b --disable-autoexec rig-demo/good.blend --python-exit-code 1 -P scripts/rig_audit.py -- --manifest examples/rig-check/checks.json --out rig-demo/good.json
```

正常样件有 18 项检查，包括四个闭合网格和固定耳、活动耳三处销孔截面的实测净隙。要复现反例，在第一条命令的 `--out` 前加入以下一个参数，并为两条命令换用相应的新文件名。故障样件的审查命令应退出 1，JSON 仍会保存。

| 故障参数 | 可以看到的失败 |
| --- | --- |
| `--fault pivot` | 枢轴在中立态偏 1 mm。转动后两处孔边测点、活动耳对销的动态净隙和正反限位共五项失败。 |
| `--fault weight` | 管段根部顶点 0 被赋给活动耳骨，权重和仍为 1。区域规则命中该顶点，真实动作还测出固定端移位。 |
| `--fault flex` | 将耳片一个金属顶点交给静止骨骼，随臂旋转后形状改变。刚件全顶点复核可定位。 |
| `--fault oversize_pin` | 孔径保持 2.10 mm，销外径从 2.00 加至 2.40 mm。中立姿态实测单侧净隙从 +0.050 变为 −0.150 mm，固定耳与活动耳的三处表面配合检查失败。 |

把 [样件检查清单](../examples/rig-check/checks.json) 复制到项目，改为已校准的场景、零件、基准及限值。按以下约定扩展项目：

- `scene`、`rest_frame` 与 `frames` 指定装配基准和样本，支持小数帧。单项设置 `frames` 可验证某个端点确实到达。用量测依据确定公差；样件的阈值仅适用于其自建几何。有单位场景默认将 Blender 单位按 `scale_length × 1000` 换算为毫米，无单位场景需显式指定 `mm_per_blender_unit`。
- `distance` 量两个锚点的世界空间距离。`axis_gap` 把 A 减 B 投影到指定对象局部 `direction` 对应的世界正方向，结果可带负号。锚点 `point` 使用对象局部 Blender 单位，跟随对象变换；跟随蒙皮、约束和修改器后的真实网格表面时使用 `vertex`。测点配合只能证明这些位置的观测，两站的半径和一个轴向点也不足以描述完整孔壁。需要时增加周向测点、面法线、全表面或实体审查。
- `ray_gap` 从同一横截面轴心向外发射射线，对两个求值网格分别取第一个命中点。报告孔壁距离 `outer_hit_mm`、轴表面距离 `inner_hit_mm` 及两者之差。负值表示该射线上出现实体占用冲突。选择位于两件有效配合长度内的测面，确认首个交点落在目标面上；对非圆、锥形、偏轴或局部突出处增加角向与轴向样本。样件刻意使用十二边形，活动耳上侧测点在旋转中的最小已测净隙约 0.0142 mm；实际加工尺寸需使用有精度依据的几何。
- `closed_single_shell` 适用于预期为单一连通闭合表面的零件。按共享边检查壳数、非流形边／顶点和相邻面绕序，再测有向体积。样件中立帧的固定耳、活动耳、销、管段各为一个闭壳，体积约 +178.770、+178.770、+25.800、+36.000 mm³。自相交需另检；内部独立空腔、多壳零件或开放布片应按实际拓扑分别审查。
- `rigid` 以装配基准帧和三个远离共线的顶点建立随体坐标系，逐帧比较所有求值顶点，报告最大形变与顶点号。对改了顶点顺序或拓扑的网格重建对应关系后再测，统一坐标精度。只测保形可能放过整块脱位，必须配合装配锚点和运动终点。
- `skin` 检查原始网格上目标骨架的变形权重、骨架修改器开关和指定解剖区域的骨骼白名单。目标格式要求时加入 `max_influences`。用顶点测点另验蒙皮后的锚定、弯曲截面与运动幅度。图像目检和其他修改器、形态键、包络及复杂混合驱动的专门检查仍需执行。
- 报告写入场景和清单 SHA-256、Blender 版本、尺度、样本及失败项。使用已冻结且打包或归档依赖的场景。后台默认按视口依赖图求值；另核对最终渲染中的细分、可见性和模拟缓存。需要可信自定义驱动时，按项目运行环境启用或烘焙，再重复动作见证。给每轮修复保留独立报告。

## 交换文件与交付

在目标引擎或软件的空项目中打开发布版交换文件，记录导出选项、导入器版本、单位换算、轴向和帧率。以一个独立已知尺寸、固定锚点、正负末端和柔性截面为基准，与原生场景在相同动作时间比较。导入三角化、拆顶点或重排索引后，重新按几何特征配对测点。核对材质、纹理、骨数、层级、权重、剪辑起止、骨骼姿态和循环返回。目标格式不能传递的约束与驱动先烘焙到可传递骨骼／对象曲线或形变通道，再比较回读结果。原生控制架、基准姿态、可编辑网格、贴图、测试动作、导入参数和未验证范围都随交付保存。
