# 给概念和草图配参考

已知对象、用途或一个关键动作，就开始找参考。把第一批案例带入客户访谈，让客户指着具体部位谈取舍。若客户已有指定原型或必须保留的设计，先把它标出来。相似产品可以启发方案，目标型号的尺寸图、实测或客户批准的图纸才可用于评定几何还原误差。

## 怎么找

1. 从草图提取对象、使用者、场景、动作和最难解释的一处连接。比如“可折叠阅读灯”先区分支在桌上、夹在书上两种接触方式，再看灯头怎么越过书脊。角色项目可改查体态、关节活动与服装受力。
2. 针对每个未知点实际搜索。用“对象＋功能＋品牌或设计师”找同类，用“动作＋接触对象＋说明书／侧视图／motion sequence”找机构，用“材料＋表面处理＋局部照片”和“对象＋场景＋设计方”找材质、镜头和尺度。跨品类时搜索共同动作，例如用折叠支架研究收拢顺序。
3. 打开原始页面，核对作者或品牌、型号、版本和支持观察的具体图、时间码或段落。结构优先选有尺寸、装配顺序、多个状态的原始资料，材质优先选有材料说明和清晰照片的页面。每个案例至少回答一个此前未解的问题。删掉重复角度和只有氛围、无法解释用途的条目。
4. 交给客户两三条真正有区别的候选方向，标明会影响的使用体验和取舍。把链接落到产品、图纸或设计师个案页，让客户可直接打开看图。遇到失效或受限的来源，换一个能核对的来源。无法联网时注明缺口，先用客户给的资料或原创示意，恢复检索后补上。

## 每张参考卡写什么

| 字段 | 记录方式 |
| --- | --- |
| 身份与出处 | 案例编号、作者或品牌、确切型号／版本、原始链接、查阅日期、图名／页码／时间码。 |
| 资料中的事实 | 写一条可复核的外观、运动、材料或镜头观察。引用尺寸时记单位、基准、状态与适用型号。 |
| 给本项目的启发 | 指出借鉴的特征、要解决的客户问题和有意排除的品牌特征。看不到的机构、倒角半径、内壁和布线标为未知。 |
| 可验证的下一步 | 写清要改哪一处草模、测哪个尺寸、测试哪些姿态，或在哪张图里看哪种材质反应。 |
| 素材使用范围 | 公开网页可用链接指引查看。复制到资料包或公开展板的图片、CAD、贴图和品牌素材，应有对应的再分发授权及署名记录。客户的未公开草图可用通用词研究，上传原图到外部服务须有对应授权。 |
| 客户意见 | 限定到具体特征，记“采用／排除／待定”、选择依据、确认人和日期。客户尚未回复时保留“待定”。 |

## 如何影响后续制作

- 请客户说出最想保留的特征、最想排除的特征及原因。把决定写成可检验的要求，如“软面夹爪要避开正文”，并关联参考编号、零件、姿态或镜头。
- 草模阶段用同一观察角度比较候选轮廓，同时展示一次收拢或弯曲的中间姿态，暴露端点图看不到的干涉。记录批准的选择及待验证的尺寸。只对有尺度和坐标基准的真实资料报告毫米差异。
- 给渲染师的参考具体到画面任务。例如“用一张合灯状态侧视图说明收纳厚度，再用开灯近景检查扩散片和纸面细节”。最终镜头里的尺寸、形态、姿态与材质以项目自己的基准模型和已确认的决定为准。
