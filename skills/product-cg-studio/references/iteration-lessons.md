# 三组项目复盘与复验方法

手柄案例从现有高模接手。云台相机和折叠产品案例以公开尺寸、手册和照片重建。三者共有的返工原因是早期画面遮住了错误，或量测回答的问题比验收问题窄。下列数值来自具体工程，换产品时重新定标。

## 怎样处理一次「看起来不对」

1. 留下最小可复现画面。记源版本、部件、姿态、相机、帧、灯光和原尺寸裁切。把反馈写成能被验证的问题，例如「镜圈与前窗哪一道边界偏了」「收纳到一半时由哪块支座承托」。用户提供的圈注图可作定位，需用源模型复现。
2. 找一个能区分原因的观察。轮廓用标定叠图，深度用侧后视图或实切，相交用求值后网格，着色用白模和几何法线，姿态用固定机位动画。优先增加能推翻当前解释的角度。拟合用过的照片与独立留验资料分别记录。
3. 在副本修改导致问题的最小结构，保留旧版。每轮并排输出**同机位改前、改后、参考**和局部原像素。登记获益、变差的项目与未知项。新版本接入原灯光和动作复测，检查邻件、背面、极限与导出回读。
4. 若问题会反复发生，把失败工况做成回归。用临时副本故意移动、解绑或遮住出问题的对象，验证检查确实能定位失败部件和帧。再从定稿只读副本重跑，记录两个结果。无版本日志时，仅列出有证据的变动。

## 从反复出现的症状选择下一步

| 历史观察 | 下一次怎样发现与修正 | 怎样判读证据 |
| --- | --- | --- |
| 手柄横排的三个方向都能辨认，后来明确需要按钮面向上平放。改变画幅仍可能拍错产品的面。 | 先命名向上表面、朝前部件、支承点。绕装配根节点改姿态，用正俯视确认按钮朝向，再从台面侧方确认高度、接触和阴影，最后布置横幅与竖幅。 | 三姿态合照、独立整机照和不同画幅各自对应一个需求。交付前对照镜头清单逐项勾选。 |
| 相机正面剪影的匹配率提高后，侧面仍看到了支臂穿入后壳。双镜之间的亮斑另涉及相交三角面与着色法线。 | 分别对齐外圈、开口、承座和侧后支撑。用固定光照依次对比材质、白模、线框与法线，按判因重建前壳过渡或处理着色。修镜圈时同时检查下方字标可见面积。 | 正面投影、三维实体、原像素局部各保留一项结果。某次前壳局部计有 26 对相交三角面，改版后同一检查为零。切换布光后亮斑消失仍需回查几何。 |
| 转屏时双摄也动是一种表面观察。拆开看，屏幕自转、开机事件和云台回正分别有自己的条件。 | 核对手册或可辨认动作的实拍，分别定义转屏、云台与亮屏状态，再用事件排时序。镜头中保留固定机身，用组合姿态检查屏框与支臂、后壳与横桥。 | 运动轨迹和限位按已测范围报告。重建时加的联锁、停放角和时序注明假设。穿过静态走线孔的探针只验证该段孔道。 |
| 折叠模型的零件一起运动，看完整动画仍看不出固定座占用了壳体空间。另一次修订使同一标记点的收纳位置改善，整机展开长度偏差却增大。 | 除活动件外，对固定嵌件也逐对检查承座、实体共占和装入方向。收纳、展开及中段跟踪同一个几何点，并回测整机三个方向的包络。 | 将同一张手册图上的拟合、独立视图的验证及产品全局偏差分开列。记录局部改善造成的代价。只有照片时保留对真机公差的未知结论。 |
| 由图纸重建的热端能排出拆解序列，但侧插零件在画面内彼此遮挡，微距也曾裁掉喷嘴出口。 | 先用低成本预演与目标尺寸关键帧检查每个零件的画面投影。按出口、固定点等可见任务修机位，留实际装配机位复核原连接。 | 同一热端工程在副本中人为下移喷嘴 1 mm，原本通过的 106 项中有 19 项失败。此例可验证检查是否有辨别力，测试位移不构成其他产品的验收阈值。 |
| 为官网版位制作的手柄图、尺度实验、历史配色工程与后补的制作过程图，用途与来源不同。快节奏相机片还增加了不出现产品名称的要求。 | 在工单写明型号、成图用途、允许出现的文字、动作和渠道。将产品图与概念图分别编排。逐镜列出画内文字、屏幕内容、所用几何及动作版本。 | 在完整编码上检查片头、画内文字、切点、尾帧和发布裁切。电脑里的手机视口仅能证明该环境下的排版与解码。 |

## 再次接手时应留下什么

- 一张能逐项追溯的修订单。例如「镜窗／正面原尺寸图／前壳过渡和镜圈深度／改后照片投影更准／侧缘厚度待实测」。附一张来自其他视图或姿态的反例，标出是否仍成立。
- 一条真实的制作链。保留收到的输入、白模、结构分色或线框、单灯、正式材质、最终场景和交付图。历史截图与重开工程补拍的截图标记时间和版本。已有高模从导入写起。历史第三方模型的成图与新建模型的同机位重渲分别归档。
- 一个能定位原件的索引。按项目、型号、源版本、镜头与用途整理母图、成片、渠道衍生图和工程。预览可点回原尺寸文件。分享时核对外部素材各自的使用范围，并以另一目录中的可携副本验证贴图、字库、模板与缓存路径。
