# 产品静帧与 CMF 精修

## 接手旧工程

先从原件选一张基准图，记录源文件版本、场景、相机、帧和关键部件。另存工作副本，重开并渲染小样。某个按键只在特定镜头错位时，检查该帧的父子关系、约束与遗留关键帧。只修确认异常的对象，同时保留有意设计的活动状态。

对要求保持外形的产品，以装配根节点为基准，比较主要部件的相对变换、网格、UV 和材质槽。可结合网格指纹与固定机位轮廓叠图定位差异。整体搬动或旋转应保持零件之间的关系。补贴图后从新的工作目录重开工程，确认依赖都能解析。品牌、字标或法规印字缺少可靠原稿时，在交付说明中写出具体位置和缺件。

## 为每张图分配任务

先写出这张图要回答的问题和最终画幅，再布置相机。整机、细节或使用状态可按下面的方式选用。

| 想回答的问题 | 相机与布置 | 查看成片时的判断 |
| --- | --- | --- |
| 产品长什么样，按钮在哪里 | 三分之四视角交代厚度，正投影或长焦正面图用于比较布局 | 轮廓完整，重要零件在发布尺寸上仍可辨认 |
| 产品怎样平放或翻面 | 明确哪一面朝上、哪一侧朝前，用一个装配根节点旋转产品；以模型自身的轴向和可识别部件验证方向 | 支撑点触地，阴影从接触处延伸；留意近地零件是否穿透 |
| 同时展示几种摆法 | 横排合照可复制链接实例，各自设置姿态根节点，共用台面、相机和灯；多角度独立成图可为每个信息点单设相机 | 合照各姿态互不遮挡；独立图分别能交代新的结构或表面 |
| 官网横幅与手机首屏分别怎么用 | 依据两处标题、按钮与裁切空间取景；横图裁竖图切掉轮廓时，单设竖幅机位 | 在目标视口复核完整度、文字留白和视觉重心 |
| 用户如何连接或操作 | 对准功能部件，用对应型号资料核对接口、连接两端、按键或指示灯状态；道具服从功能说明 | 一眼能看清操作关系，光色、线缆走向及关键细节可信 |

## 从白模到材料定稿

1. 在中性色环境下渲染白模，先看轮廓、转角、装配缝和透视。对照材质时固定相机、姿态、帧、曝光及显示变换，每次只调整正在审查的变量。
2. 按真实部件分材质。用大面积软光观察壳体曲面渐变，用窄反射检查透明键帽边缘与下方标记，用侧后方掠射光检查橡胶或压纹的颗粒尺度。若反光遮字，先移动灯或反光板，看清问题再改材质。实拍参照应与型号、颜色和表面处理相符。
3. 以原尺寸局部对照纹理方向、接缝、粗糙度变化、透明边缘与噪点。同一标准配色在整套图使用同一组基础材质；单独命名提案配色、剖视、发光工作状态等有意变体。只有参考图而缺少实物色样时，记录颜色的视觉依据与精度边界。
4. 修图可清理渲染瑕疵、微调色调和局部对比。错位、孔位失真、浮空、材质投射和错误标识应回到工程修改，再渲染受影响的镜头。局部调整后与未改区域的反射、锐度、纹理和颗粒比较。

纹理丢失或材料发灰时，先检查贴图的用途与解码。常见的彩色 PNG 底色使用它实际编码的色彩空间，粗糙度、金属度、法线和高度数据按非颜色数据读取。核对法线贴图方向及强度，按可见部件的尺寸设置纹理重复周期。原型上的滚花若会改变近景剪影，就用几何表现；只在光泽中可见的细车纹可先试凹凸或沿加工方向的粗糙度变化。

材质审查存一张固定相机与曝光的对照图。在金属旋钮、哑光壳体、透明窗口上分别取原像素小块，看高光宽度、方向和下层细节。细纹消失时，对照降噪前后的同帧，看纹理是否已被滤掉，再决定调映射、采样或降噪。若交付分层 EXR，在场景线性空间调整反射等通道，最后一次性应用目标显示变换。

## 验收与交付

- 先看联系表，检查镜头分工、型号一致性和明暗节奏；再按输出原尺寸查看高反差边缘、按键标识、握持表面与落地处。对于材料或结构上的问题，留下一组同机位修改前后图。
- 解码交付文件，核对原生宽高、位深、通道、色彩配置。透明图叠到深浅两种底色，检查白边、黑边和意外地影。交付 EXR 时回读所需通道和名称，记录显示变换与 Alpha 约定；交付印刷文件时按实际版面尺寸计算有效像素密度。
- 交付清单把成片对应到源工程、场景、相机、帧和原始输出。用发布端真实尺寸检视裁切、标识和小字。补做的白模、分色或单灯复现标明生成时间、所用工程；收到已有高模的项目，从导入阶段开始描述制作过程。
