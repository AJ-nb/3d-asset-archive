# Blender 工程界面截图

这六张图于 2026 年 11 月 27 日重新打开三个已保存的 Blender 工程后拍摄。发布时可标注“原工程重开实录”。截图日期与历史工程文件的修改时间分别记录在同目录的《界面截图索引.csv》。

每张原图均由 Blender 5.2.3 LTS 的整窗截图命令直接保存为 2560 × 1369 PNG。原图保留工作区、Outliner 和编辑面板，未裁切或后期拼接。取证期间调整了视口、活动对象与展示帧，源工程只读，核验脚本比对了读取时与截图完成后的源文件 SHA-256。

| 编号 | 源工程 | 截图中可核对的信息 |
| --- | --- | --- |
| 01 | layout.blend | 机身体块、云台体块、四个臂形引导、四个旋翼占位，共十个粗模对象。 |
| 02 | first-assembly.blend | 早期装配模型，第 32 帧。三镜头云台、机壳轮廓及各旋翼已经成形，右侧列出独立零件。 |
| 03 | Mavic-4-Pro-Rear-Fit-Final.blend | 终版几何以统一浅灰色显示，可以对照完整机身、云台、机臂和轮毂的形态。这里的“白模”是终版的几何检视状态。 |
| 04 | 同上 | 镜头对准左后肩装配位置，防护套、根部座圈及端盖进入多对象网格编辑，其余壳体保留上下文。 |
| 05 | 同上 | 第 52 帧的折叠中间态。两根后臂折叠骨骼、动作通道、Z 旋转关键帧和当前姿态来自该工程。 |
| 06 | 同上 | 机壳材质的坐标、噪声、范围映射、凹凸、Principled BSDF 与材质输出六个节点。为呈现连接而在内存中排布节点并收起部分插口，保留源工程中的参数和连线。上方为按材质基础色显示的实体视口。 |

“工具/记录”保存每张图对应的场景、帧、活动对象、视口范围及编辑器位置；动作和材质截图还包括骨骼或材质连线。安装 Pillow 的 Python 可运行“工具/核验索引.py”重新检查 PNG 和工程 SHA-256；“工具/重新截取.py”可使用本机保留的原工程重拍，各图的具体窗口设置保存在“工具/原生界面取证.py”。
