# 后肩装配复验

**两侧后臂现可绕各自一根固定轴，在完整模型中把同一桨冠从手册的展开位置送到收纳位置。** 展开四电机的平面比例和全程后桨避壳均有实测。展开整机长度相对 DJI 规格的误差增加了 12.41 mm，收纳宽度仍多 24.35 mm。这一版可用于观察后臂的装配与动作，整机尺寸复原仍未完成。

检验对象是可编辑的 203 件整机，第 1 帧展开，第 57 帧收纳，至第 121 帧复位。原生工程 SHA256 为 `57b641958dae8172326e534ede99674fdff11af6f9df332058352f71fc6e3463`。前臂、机身、云台沿用 V6。本文毫米均为模型单位，数值末位用于复算。[打开 Blender 工程](Mavic-4-Pro-Rear-Fit-Final.blend) · [原生网格测量](native-measurements.json)

## 四个假设及其反例

1. **只放宽原轴限位。** 原 V6 轨道转满 360°，旧展开冠到新收纳目标最近仍差 70.32 mm。将展开冠修到新坐标后，沿旧轴的整圈最近误差反增至 84.38 mm。[整圈解析反例](original-axis-counterexample.json)
2. **平移肩座，用竖轴把两个平面端点接起来。** 平面上可解。保持冠高的实际三维试样中，右后梁在收纳端附近与折起的前肩套相交，最大约 4,699 mm³。[试样几何检查](trial-checks.json)
3. **倾斜单轴，保留原后冠高度。** 折叠段可通过，原来停车角的叶片可穿入主壳约 9 mm³。重设两后转子停车相位 7° 后，收臂段通过；桨叶打开整圈转动时仍会擦入壳体，单叶最大约 72 mm³。四叶实际扫掠直径约 266.57 mm，DJI 公布直径 267 mm。[叶尖与机壳的高度试探](tip-diagnosis.txt) · [DJI 桨叶参数](https://repair.dji.com/help/content?customId=01700006559&documentType=&lang=en&paperDocType=ARTICLE&re=US&spaceId=17)
4. **倾斜单轴，同时校正后电机高度。** 先按独立送检侧视比较两排冠心的离地高差，再检查全圈包络。旧冠高上升 11.5 mm 时仍检出穿壳，上升 12.0 mm 后通过。后桨避壳的连续下界见下表。将新轴进一步内收至 |X|=42、Z=79 的同族试样会使主壳与肩套相交约 387 mm³；|X|=45、Z=77 的试样仍有约 22 mm³。上述反例保留了既有壳体和电池边界，更改这两者会改变可行解。[高度阈值对照](tip-threshold.txt) · [肩轴横向移位反例](raised-screen.txt)

## 本机复算

打开上方原生工程后，可在 Blender 后台运行 [readback.py](readback.py) 导出实际三角网格和各帧矩阵，再以 Python 环境变量 `REAR_TEST=verify_solids.py` 运行同一文件，重新得到 28 姿态的精确体积。对原生工程执行 [native_sweep.py](native_sweep.py) 重跑 902 个姿态及止挡，以 [native_rear_sweep.py](native_rear_sweep.py) 读取该存档网格和实际首末姿态，重跑 181 个后臂角度；用普通 Python 执行 [measures.py](measures.py)、[beam_sections.py](beam_sections.py)、[continuous_blade.py](continuous_blade.py) 可重算尺寸、截面和连续避壳。复算包随附原 V5 动作检查函数和同级 V6 工程。脚本分别需要 Blender 及装有 NumPy、Pillow、Manifold3D 的 Python 环境。输入几何的 SHA 已校验。历史低冠试样的环境量为 `M4_REAR_RISE=0`，本版为默认的 12 mm；所有已发布数字均来自冻结工程或另行标明的失败试样。
