# Mavic 4 Pro 装配与摄影的复验规则

1. 对两个姿态配准时，跟踪同一零件上的同一个可见点。记录图源、缩尺依据和参与拟合的尺寸，再用独立的视图或整机尺寸复核。逐毫米切片用于描述当前网格；声称对实物的误差需要独立的测量基准。
2. 改动铰链、梁长或安装高度后，分别记录展开与收纳的长、宽、高，保留量测坐标系、拆桨口径和决定各个极值的零件。局部目标改善时，照样列出整机尺寸退步的项目。
3. 停桨折臂和展开转桨分别测试。折叠测试驱动保存的刚性关节，包含止挡与连续组合姿态；展开测试保留有依据的桨径，对每片桨扫过的整圈空间计算与壳体的间隙。输出采样间距与保守下界，记录可重复的失败姿态。
4. 签收前，在新进程重新打开落盘的 Blender 工程。对相邻和不相邻的三角形分别检查异常接触、自相交与薄折面，在侧光下看同一区域。网格发生变动时，重新导出同版 GLB、截面、静帧和电影，并核对它们的原生工程 SHA-256。

本轮触发这些规则的实例、各自修复范围和残余误差见[后肩装配复验](rear-shoulder/后肩装配复验.md)。整体项目的更早规则与报告保存在交付包的 V6 基线中。
