# 桌面讲课相机 · 内部模拟访谈

由独立执行的 AI 设计师提问，另一位 AI 模拟委托人回答。下表记录本轮实际往返的问题、答复和仍待实测的事项。

阶段图可读到横置屏、正面操控和侧下方开口。图中还没有云台头。设计师重开 V7 后从物件名称与空间位置确认，模型的 USB-C 位于底面。侧下可见形状不足以指认为 USB-C。

| 实际发出的问题 | 内部扮演委托方的回复或明确未知 |
| --- | --- |
| 1. 电脑放在相机哪侧、线往哪边走？ | 电脑在讲者右手边，沿右侧桌面走。 |
| 2. 镜头与坐姿脸部需平视或可向上仰？ | 俯仰委托设计师。 |
| 3. 主要拍胸像还是包含桌面教具？ | 拍胸像。 |
| 4. 使用时要同时从座位看到屏幕预览吗？ | 屏和镜头都朝讲者，要能坐着看预览。 |
| 5. 桌沿可让支架夹住、还是必须全放台面？ | 全部在台面。 |
| 6. 单手提起机器时支架应随走还是留在桌面？ | 可以让底座留在桌面。 |
| 7. 收袋时希望支架仍挂在机身还是可拆后并排装？ | 可拆后并排放。 |
| 8. 收袋前可以拔线吗？ | 可以。 |
| 9. 习惯哪种插头或线材（直头、弯头等）？ | 先看普通直头 USB-C，插头尺寸未量。 |
| 10. 支架可以包住下端外壳多少，可以遮挡哪些部位？ | 优先保留原机轮廓和正面操控；实际允许包覆高度未知。 |
| 11. 袋口、键盘和机身之间，最想先压缩哪个方向的占用？ | 先看数字面积与方向；袋口与桌尺寸尚未量，未指定压缩方向。 |
| 12. 是否须承担误碰拉线后的持续稳定？ | 抗拉线稳定性保留待证。 |

委托的设计选择为低托、坐姿对应的上仰、转接方向、支撑方案与镜头。设计师选 A 平底托，底壳上托原机，低侧壁导向，原机可提起。B 用同一转接头配三片旋转脚，只在袋子对宽度特别苛刻时值得继续试。B 收后比 A 更长。两种路线都需确认底部接口及电气方案。

- DJI Osmo Pocket 3 FAQ 的 1/4 英寸手柄段说明，手柄将底部连接转到后侧，可在放置时充电。这支持用外置附件改变插线面的构思。本轮将输出面移到讲者右边，转接电路、锁扣和与 V7 的实物适配均待设计确认。[DJI FAQ](https://www.dji.com/osmo-pocket-3/faq)
- Peak Design Mobile Tripod 产品图可对比手机支架展开与贴平收合。产品说明列出带防滑脚垫的铝制支脚。B 借鉴展开／收合的状态分工，本轮使用共轴水平扇开的三片原创脚板，其厚度差和脚垫碰撞需自行验算。[Peak Design 产品页](https://www.peakdesign.com/products/mobile-tripod)
